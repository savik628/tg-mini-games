### 3.2. Поведение при истечении лимита минут
- **Предупреждение T-60s**: платформа запускает пульсацию таймера и отклик `warning`. Игра продолжает идти без зависаний.
- **Окончание лимита (T-0s)**: игра мягко останавливает текущий раунд и передает набранные очки в системный оверлей через `window.PlatformSDK.gameOver(resultData)`.

## 4. Результаты раунда и передача данных

> [!IMPORTANT]
> Игра **не рисует собственный экран Game Over**. Все данные передаются в системный оверлей платформы.

### 4.1. Формат передаваемой статистики
```javascript
window.PlatformSDK.gameOver({
  score: 0, // Итоговый счет раунда (Number)
  isVictory: false, // Флаг победы или поражения (Boolean)
  stats: {
    // Кастомные метрики раунда для отображения в системном окне:
    primaryMetricName: "Дистанция",
    primaryMetricValue: "420 м",
    coinsEarned: 35
  }
});
```

## 6. Чек-лист готовности к сдаче в каталог

- [ ] Визуальный стиль игры адаптирован под темную тему платформы (Dark Slate `#0f172a`).
- [ ] Игра управляется одной рукой на мобильном экране без горизонтального скролла.
- [ ] Корректно вызывается `window.PlatformSDK.gameReady()` после загрузки ресурсов.
- [ ] Подключены все типы Taptic-отклика (`light`, `heavy`, `success`, `error`).
- [ ] Отработана пауза при срабатывании события Telegram BackButton.
- [ ] Результаты раунда корректно передаются в `window.PlatformSDK.gameOver()` без вызова собственных кастомных экранов завершения.
- [ ] Отсутствуют любые внешние ссылки, сторонние баннеры и платежи.
