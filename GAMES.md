## 1. Архитектурная оболочка и интеграция

Платформа «Мини игры» построена по принципу единого портала. Игра никогда не запускается как самостоятельный обособленный сервис со своим ботом, отдельным профилем или независимой базой данных пользователей. Каждая игра подключается как дочерний модуль или встроенный Iframe/компонент в общую оболочку платформы.

### 1.1. Жизненный цикл игры
1. **Инициализация**:
   - Игра загружается в контейнер оболочки.
   - Оболочка передает в игру контекст сессии (`session_id`, `app_id`, настройки звука/вибрации, локаль, статус пользователя).
2. **Старт игрового процесса**:
   - Игра вызывает метод готовности платформенного SDK: `window.PlatformSDK.gameReady()`.
   - Оболочка инициирует серверную сессию (`POST /session/start`). Сервер валидирует баланс минут или наличие Plus-подписки.
3. **Геймплей и учет времени (Heartbeat)**:
   - Списание минут ведется сервером через Heartbeat раз в 30 секунд.
   - Игра обязана корректно сообщать оболочке о паузах и фоновом режиме (Visibility API). Если игра свернута или на паузе — списание минут приостанавливается (`window.sessionMgr.pause()`).
4. **Завершение раунда / сессии**:
   - При выходе в лобби платформы вызывается `window.PlatformSDK.endSession()`. Сервер фиксирует окончание времени игры.

## 2. Обязательные экраны и состояния

Каждая игра обязана реализовать следующий набор типовых экранов и состояний в соответствии с дизайн-системой ([UI-KIT.md](file:///Users/savelijkoselev/Library/CloudStorage/GoogleDrive-savelii.k28@gmail.com/Мой%20диск/2026-2027/PET/tg_mini_apps/UI-KIT.md)):

```
[Экран загрузки / Сплэш]
         │
         ▼
[Стартовый экран игры (Интро / Обучение)]
         │
         ▼
   [Игровой экран] ◄────► [Экран паузы]
         │
         ▼
[Экран результатов раунда (Win / Game Over)]
         │
         ├──────────────────────────────┐
         ▼                              ▼
[Сыграть снова]             [Выход в главное меню платформы]
```

1. **Экран загрузки (Splash / Loader)**:
   - Фирменный лоадер платформы (spinner / progress bar), название игры и краткая подсказка/совет.
2. **Стартовый экран игры (Intro)**:
   - Название, ключевая цель раунда (в 1-2 предложениях), понятная кнопка «Играть», кнопка настроек (звук, тактильный отклик Taptic Engine).
3. **Экран игрового процесса (HUD / Playfield)**:
   - Игровое поле, счетчик текущих очков/прогресса, кнопка «Пауза», компактный индикатор оставшегося времени игровой сессии (транслируется из оболочки).
4. **Экран паузы**:
   - Открывается по тапу на иконку паузы либо при системных событиях Telegram (сворачивание, звонок). Автоматически останавливает таймер списания минут.
   - Кнопки: «Продолжить», «Начать заново», «Выйти в меню платформы».
5. **Экран результатов раунда (Game Over / Victory)**:
   - Итоговый счет, лучший результат (High Score), полученные достижения.
   - Кнопки: «Сыграть снова», «Выйти в платформу».

## 3. Интеграция с Platform SDK

Каждая игра взаимодействует с платформой через глобальный интерфейс `window.PlatformSDK`:

```javascript
// Пример взаимодействия с Platform SDK
window.PlatformSDK = {
  // Сигнал готовности ассетов и рендера
  gameReady: () => {
    window.parent.postMessage({ type: 'PLATFORM_GAME_READY' }, '*');
  },

  // Уведомление об изменении очков / состояния
  updateScore: (score) => {
    window.parent.postMessage({ type: 'PLATFORM_SCORE_UPDATE', score }, '*');
  },

  // Завершение раунда
  gameOver: (resultData) => {
    // resultData: { score: 1250, victory: true, stats: {...} }
    window.parent.postMessage({ type: 'PLATFORM_GAME_OVER', data: resultData }, '*');
  },

  // Запрос на закрытие игры и возврат на главный экран платформы
  exitToLobby: () => {
    window.parent.postMessage({ type: 'PLATFORM_EXIT' }, '*');
  },

  // Вызов нативной тактильной отдачи Telegram
  haptic: (type = 'light') => { // 'light' | 'medium' | 'heavy' | 'success' | 'warning' | 'error'
    if (window.Telegram?.WebApp?.HapticFeedback) {
      if (['light', 'medium', 'heavy'].includes(type)) {
        window.Telegram.WebApp.HapticFeedback.impactOccurred(type);
      } else {
        window.Telegram.WebApp.HapticFeedback.notificationOccurred(type);
      }
    }
  }
};
```

## 4. Обработка системных событий и лимита минут

1. **Исчерпание минут в процессе игры (`Time Exceeded`)**:
   - Когда серверный Heartbeat возвращает `error: "Minutes limit reached"`, платформа генерирует событие перехвата.
   - Игра обязана мгновенно поставить геймплей на паузу и показать системный Paywall / модальное окно пополнения минут через платформенный роутер.
   - **Запрещено** сбрасывать прогресс текущего раунда до закрытия модального окна. Если пользователь покупает Plus или пакет минут — раунд возобновляется.
2. **Офлайн-режим**:
   - Доступен исключительно пользователям с активной Plus-подпиской (проверяется валидным `offline_token`).
   - Если игра запущена в офлайн-режиме, все результаты раундов кэшируются в IndexedDB/localStorage и отправляются на сервер пачкой строго при восстановлении онлайн-соединения.

## 5. Строгие запреты для разработчиков игр

Согласно разделу 16 [RULES.md](file:///Users/savelijkoselev/Library/CloudStorage/GoogleDrive-savelii.k28@gmail.com/Мой%20диск/2026-2027/PET/tg_mini_apps/RULES.md):
- ❌ **Запрещены собственные платежные шлюзы и Stars**: игра не имеет права создавать свои инвойсы, запрашивать оплату Stars напрямую или продавать виртуальные товары в обход серверного API платформы.
- ❌ **Запрещен собственный баланс минут**: игра не может начислять, продавать или списывать минуты по собственному усмотрению.
- ❌ **Запрещены сторонние реферальные ссылки и боты**: игра не может уводить пользователя в отдельные боты, каналы или внешние веб-сайты.
- ❌ **Запрещена самовольная реклама**: запрещено встраивать внешние баннеры, interstitial или rewarded video. Реклама запускается только платформой и только по явному действию пользователя Free-тарифа (+5 минут).
- ❌ **Запрещено принудительное удержание**: игра обязана предоставлять кнопку выхода в платформу в любой момент.
- ❌ **Запрещено отклонение от дизайн-системы**: шрифты, цветовая палитра и стили кнопок должны на 100% наследоваться из [UI-KIT.md](file:///Users/savelijkoselev/Library/CloudStorage/GoogleDrive-savelii.k28@gmail.com/Мой%20диск/2026-2027/PET/tg_mini_apps/UI-KIT.md).
